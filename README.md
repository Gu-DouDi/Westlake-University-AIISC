# AI交叉科学社网站

本目录包含社团网站文件，以及一个可在 macOS 上双击运行的局域网分享工具。启动后，这台电脑会临时作为网页服务器；连接同一 Wi-Fi 的手机可以扫描二维码访问网站。

## 一键启动

1. 确认电脑和需要访问网页的手机连接到**同一个 Wi-Fi**。
2. 在 Finder 中打开本目录，双击 **`启动社团网页.command`**。
3. 第一次运行时，如果 macOS 防火墙询问是否允许 Python 接受传入连接，请选择**允许**。
4. 浏览器会自动打开二维码页面。用手机相机或微信扫码即可访问。
5. 分享期间请保持终端窗口开启。
6. 结束分享时，在终端窗口按 **Control + C**，或直接关闭该窗口。

网站优先使用 `8765` 端口。如果该端口已被其他程序占用，启动程序会自动改用下一个可用端口。启动后，终端窗口也会显示实际的手机访问地址，例如：

```text
http://192.168.1.23:8765/
```

局域网 IP 地址会随 Wi-Fi 环境变化，每次分享请以启动程序本次显示的二维码和地址为准。

## A4 二维码海报

启动网站后，二维码页面提供 **“打开 A4 二维码海报”** 按钮。海报会自动使用本次启动生成的局域网地址，因此无需手动替换二维码。

1. 点击“打开 A4 二维码海报”。
2. 在海报顶部点击 **“下载 A4 海报 PDF”**。
3. 浏览器会直接下载 `AI交叉科学社-网页二维码海报.pdf`。

下载的 PDF 固定为 A4 纵向尺寸，并以网页中的海报画面生成，不需要再调整浏览器打印选项。需要纸质版时，直接打开该 PDF 并按 100% 比例打印即可。

如果电脑更换 Wi-Fi 或局域网地址发生变化，请重新启动网站并重新打印海报。旧海报上的二维码不会自动更新。

## macOS 阻止脚本时

如果双击后提示无法打开：

1. 在 Finder 中右键点击 **`启动社团网页.command`**。
2. 选择“打开”。
3. 在确认窗口中再次选择“打开”。

## 指定起始端口

通常无需手动处理端口冲突。如需指定一个起始端口，可打开“终端”，进入本目录后运行：

```bash
./启动社团网页.command 9000
```

端口号可替换为 `1024` 到 `65535` 之间的数字；如果该端口也被占用，程序仍会自动向后寻找可用端口。

## 手机无法访问时

- 确认手机和电脑位于同一个普通 Wi-Fi，而不是访客网络。部分访客网络会禁止设备互相访问。
- 暂时关闭手机蜂窝网络、电脑 VPN 或代理后重试。
- 检查 macOS“系统设置 → 网络 → 防火墙”，确保允许 Python 接受传入连接。
- 重新连接 Wi-Fi 后，关闭并再次启动程序，以生成新的二维码。
- 不要使用二维码页面中的 `127.0.0.1` 地址；手机应访问终端显示的局域网地址。

## 文件说明

- `dist/`：网站页面、样式、脚本和图片。
- `启动社团网页.command`：可双击的一键启动程序。
- `serve_local.py`：局域网网页服务器、二维码页面与 A4 海报。
- `local-share/`：本地二维码与 PDF 生成组件；启动后无需联网生成或下载海报。

## 安全说明

此工具只在当前电脑上启动临时 HTTP 服务，不会把网站上传到其他平台。任何能够连接到同一局域网并知道访问地址的设备都可以打开网页。使用结束后按 Control + C 关闭服务即可。
